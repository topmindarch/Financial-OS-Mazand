# مازندشت | باغدشت — ربات قیمت‌گذاری مرکبات

ربات تلگرام برای ثبت‌نام کاربران، تأیید دستی، مجوزهای مستقل خرید/فروش، گروه‌های قیمت داخلی، قیمت مستقیم یا ضریبی، و ورود قیمت‌ها از Excel.

## وضعیت

این مخزن منبع پروژه و راهنمای استقرار را نگه می‌دارد. برای اجرای واقعی باید `BOT_TOKEN`، شناسه مدیران و اتصال PostgreSQL را در محیط مقصد تنظیم و تست نهایی انجام دهید. هیچ رمز یا کلید واقعی را در GitHub قرار ندهید.

## راه‌اندازی سریع محلی

1. Python 3.11+ و Docker Compose نصب کنید.
2. فایل `.env.example` را به `.env` کپی و مقادیر واقعی را وارد کنید.
3. اجرا: `docker compose up --build -d`
4. لاگ: `docker compose logs -f bot`
5. در تلگرام `/start` را ارسال کنید؛ مدیر از `/admin_help` استفاده کند.

راهنمای کامل فارسی در `docs/راهنمای-راه‌اندازی.md` است. ساختار دیتابیس Supabase در `supabase/migrations/202610230001_init.sql` قرار می‌گیرد.

## قواعد قیمت‌گذاری

- حساب عادی/ویژه به‌تنهایی مجوز قیمت ایجاد نمی‌کند.
- مجوز خرید و فروش و گروه قیمت خرید و فروش جداگانه و فقط توسط مدیر تنظیم می‌شوند.
- گروه‌های داخلی در پیام‌های کاربران نمایش داده نمی‌شوند.
- گروه قیمت می‌تواند مستقیم قیمت داشته باشد یا از قیمت پایه با ضریب و تعدیل ثابت محاسبه شود.
- تغییر قیمت پایه، قیمت گروه‌های ضریبی را در لحظه محاسبه به‌روز می‌کند.
- ورود Excel ابتدا اعتبارسنجی و پیش‌نمایش می‌شود؛ ثبت فقط پس از تأیید مدیر انجام می‌شود.

## امنیت

`service_role`، توکن ربات و رمز دیتابیس را هیچ‌وقت commit نکنید. مهاجرت Supabase، RLS را روشن می‌کند؛ ربات سمت سرور از اتصال دیتابیس استفاده می‌کند و دسترسی کاربران تلگرام باید در منطق ربات کنترل شود. پیش از بهره‌برداری واقعی، آزمون دسترسی مدیر، واردکردن Excel و پشتیبان‌گیری را اجرا کنید.
